# bench_lean：精益离散装配工厂布局算例集（v0.1）

公开 UA-FLP 基准（O7、vC10a、AB20、SC30、Du62）只有一块空矩形场地、部门面积和一张物流矩阵。真实项目还要考虑柱网、固定通道、装卸门、安全出口、防火规则、人流和搬运设备。本目录生成一组带这些要素的算例，并提供独立的检查器和核算器。

## 内容

| 文件 | 作用 |
|---|---|
| `params.py` | 全部参数。每个参数标 `SRC`（有公开出处，写明出处）或 `ASM`（假设值，有项目数据时应替换） |
| `generate.py` | 生成算例：由产量和工艺路线算设备数、线长、库存面积，再由单元载荷算每天搬运趟数 |
| `instances/*.json` | 11 个算例和参数表 `_params.json` |
| `evaluate.py` | 独立检查器 + 核算器（不与任何求解器共用代码） |
| `reference.py` | 考虑通道的参考解法：证明每个算例有可行解，并给出第一个要超越的成本 |
| `rowsolver.py` | 按通道分行的两阶段求解器：SA 定行和顺序，SOCP 定几何（见下文“按通道分行求解器”） |
| `baseline.py` | 基线：经典求解器（忽略真实要素，`classic`）、参考解法（`ref`）、经典解 + 合法化（`legal`）、按通道分行求解器（`rows`） |
| `fastpath.py` | 与 `evaluate` 相同的真实路径成本，向量化，快约 5 倍（求解器内部选解用；最终结果仍由 `evaluate` 复核） |
| `clearance.py` | 稳健性检查：要求通道净宽至少 1.4 m 时的路径成本 |
| `run_bench.py` | 并行批量运行：`OUTDIR 秒数 进程数 --set test 或 tune --seeds 0-19 --cfg 标签:方法[:参数]` |
| `final_report.py` | 生成最终实验的汇总表和布局图 |
| `make_tune.py`、`instances_tune/` | 调参集（种子 11–21，与测试集同规模、同形态），调参只用它 |
| `compare.py` | 两种方法对比表：可行次数、平均/最好真实路径成本、Mann–Whitney U、合并的 Wilcoxon 符号秩 |
| `test_evaluate.py` | 检查器自测：每次破坏一条规则，确认被报出来 |
| `results/` | 基线结果（云端，2026-11-16） |
| `results_rows/` | 按通道分行求解器和参考解法在同一台机器上的第一轮结果 |
| `results_tune/`、`results_ablate*/`、`results_time/`、`results_phase2/`、`results_diag/` | 调参集上的消融、时间曲线、调参和诊断 |
| `results_final/` | 最终实验（测试集）的原始结果；汇总在 `results_final/report/final_summary.md` |
| `实验记录.md`、`改进规划.md` | 每一步做了什么、结果、原因；改进计划和状态 |

## 工厂原型

收货 → 原材料库 / 外购件库 → 机加工单元（壳体、轴、齿轮）→ 热处理（共用）→ 清洗 → 线边超市 → 部装线 → 总装线 → 下线测试 → 包装 → 成品库 → 发货。部分产品族另有焊接 → 喷漆（机架）。支持部门：刀具室、设备维修、质检室、办公室、更衣室/食堂。

## 算例

规模 S（19 个部门）、M（28 个）、L（39 个）× 物流形态 I（收发货在两端）、U（同一面墙）、L（相邻两面墙），共 9 个；另有 2 个改造项目（含不可移动的既有办公楼和空压站）。

## 每个算例包含

- 厂房：尺寸、跨度和柱距、柱位、火灾危险性类别、耐火等级、是否设喷淋
- 固定通道：主通道（叉车道 + 人行道）、横向通道、次通道
- 装卸门（位置、门宽、门间距）、安全出口
- 部门：面积、最大长宽比、最短边、每班人数、是否须靠外墙、危险源
- 产品族：年产量、机加工零件、外购件数；单元载荷
- 物流：每天趟数和搬运设备（叉车 / 牵引车 / 手推车 / 输送线）；人流：每天趟数
- SLP 关系表（A/E/I/O/U 按强度排序，X 带理由和最小净距）
- 规则：疏散距离、出口间距、防火分区面积、通道宽度、出入口规则

## 检查与核算（`evaluate.py`）

硬约束：面积、长宽比、最短边、在厂房内、部门不重叠、不占固定通道和固定区域、固定部门不移动、收发货区接装卸门、喷漆靠外墙、X 级净距、疏散距离（每个角点到最近出口的直线距离）、出入口能通到通道、所有物流有路径。

成本：每个部门一个出入口（边中点，必须朝向空地或通道，朝向由局部搜索选），距离为不穿过任何部门的直角最短路。物流成本 = Σ 趟数 × 设备单价 × 路径；人流成本 = Σ 趟数 × 人员单价 × 路径。同时给出形心距离成本作对比。

## 使用

```
python -m bench_lean.generate                       # 重新生成算例
python -m bench_lean.test_evaluate                  # 检查器自测
python -m bench_lean.baseline ref LA-M-I-s1 0 60 out/
```

```python
from bench_lean.evaluate import load, evaluate
inst = load("LA-M-I-s1")
ev = evaluate(inst, rects)      # rects: 每个部门一个 [x, y, w, h]，左下角坐标，单位 m
```

## 按通道分行求解器（`rowsolver.py`）

沿用两阶段思路：离散部分（每个部门在哪一行、行内顺序）交给模拟退火，连续几何交给 SOCP（Clarabel）。

- **行**：固定通道把厂房切成区域，区域朝横向通道的一边是一行；两边都是通道就有两行，两行共用一个分割变量。部门贴着通道边，所以出入口在通道上，物流一定连通。
- **改造项目**：既有办公楼不动，从它的一边到最近通道留 2 m 通道，出入口在通道端点。
- **SOCP**：面积用旋转锥；长宽比、最短边、行内顺序、在区域内、收发货区接门、喷漆靠外墙、同一行内的 X 级净距都是线性约束。目标是出入口沿通道网络的距离乘权重（同一通道 |Δx|，不同横向通道经竖向主通道）。
- **行放不下时**：每一行加一个松弛量（行可以“超长”，按长度重罚），所以 SOCP 总有解，SA 能从不可行的状态往可行走。
- **SA**：交换两个部门、把部门移到另一行、交换同一行相邻部门；10 % 的移动是“弹出”（把一个部门移到另一行，那一行超长就把最小的部门挤到最空的行）。跨行的 X 级净距和疏散距离作为罚项。
- **选解**：SOCP 的目标只是近似的成本，中、大算例上与真实路径成本的相关性只有 0.35–0.65，所以候选解按真实路径成本（`fastpath.py`）排序，保留最好的 50 个，最后 25 % 的时间对它们做局部下降，返回的布局由 `evaluate` 复核。

最终实验（测试集 11 个算例；60 秒 20 个种子、300 秒 10 个种子；参数只在调参集上定）。成本是 `evaluate` 的真实路径成本；“变化”是 11 个算例平均成本之比的几何平均。

| 对比 | 可行 | 成本变化 | 更好的算例 / 配对 |
|---|---|---|---|
| rows 对参考解法，60 秒 | 215/220 对 207/220 | −37.8 %（−50.0 % 到 −23.6 %） | 11/11；203/203 |
| rows 对参考解法，300 秒 | 107/110 对 109/110 | −32.8 %（−42.5 % 到 −21.8 %） | 11/11；106/106 |
| rows 对“经典解 + 合法化”，60 秒 | 215/220 对 195/220 | −43.4 % | 11/11；193/193 |
| rows 300 秒对 60 秒 | | −3.7 % | 11/11；79/107 |
| 通道净宽 ≥ 1.4 m 时，rows 对参考解法，60 秒 | | −36.4 % | 11/11；196/197 |

- 经典求解器（忽略通道和规则）220 次全部不可行。
- rows 的 5 次失败在 2 个算例的固定种子上（LA-M-I-s1 种子 4、9、13、15，LA-L-U-BF-s5 种子 2），其中 300 秒批次（种子 0–9）覆盖的 3 个给 300 秒也同样失败，所以是搜索卡住而不是时间不够。
- 两种方法都按墙钟停：rows 最长 59.2 秒，参考解法 61.2 秒（含起点搜索）。
- 完整表格、每个算例的数字和布局图：`results_final/report/final_summary.md`；过程和原因：`实验记录.md` §15。

```
python -X utf8 -m bench_lean.baseline rows LA-M-I-s1 0 60 out/
python -X utf8 -m bench_lean.run_bench out/ 60 12 --set test --seeds 0-19 --cfg "rowsF:rows:elite=50,polish=0.25,eject=0.1,slack_step=false" --cfg reft:ref:count_init=1
python -X utf8 -m bench_lean.compare rowsF reft out/
python -X utf8 -m bench_lean.final_report bench_lean/results_final bench_lean/results_final/report
```

Windows 下用 `-X utf8`，否则控制台打印中文会报编码错。读写文件已统一用 UTF-8。
