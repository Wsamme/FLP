# 车间说明：液压泵装配车间

## 1. 产品
本车间装配液压泵，分两种：货车用液压泵（货车泵）和轿车用液压泵（轿车泵）。零件来自零件仓库，部分零件需先清洗；两种泵各有一条装配单元线，装好后先做性能测试，再做噪声测试，最后包装入库。车间内有 14 个作业单位。

## 2. 作业单位及功能
| 编号 | 作业单位 | 功能 |
|---|---|---|
| 1 | 清洗组 | 清洗零件 |
| 2 | 零件暂存区 | 零件临时存放 |
| 3 | 零件仓库 | 存放零件 |
| 4 | 清洗泵暂存区 | 暂存清洗后的零件 |
| 5 | 货车泵装配单元线 | 装配货车泵 |
| 6 | 货车泵性能测试区 | 货车泵性能测试 |
| 7 | 轿车泵装配单元线 | 装配轿车泵 |
| 8 | 轿车泵性能测试区 | 轿车泵性能测试 |
| 9 | 工位器具室 | 存放和发放装配用的工位器具 |
| 10 | 货车泵待测噪声区 | 货车泵等待噪声测试时的存放区 |
| 11 | 轿车泵待测噪声区 | 轿车泵等待噪声测试时的存放区 |
| 12 | 噪声测试区 | 测试泵的工作噪声 |
| 13 | 包装区 | 泵的包装 |
| 14 | 成品库 | 存放成品泵 |

## 3. 工艺流程（物料走向）
1. 零件仓库的零件送零件暂存区。
2. 清洗组与零件暂存区之间有零件往来。
3. 清洗组清洗后的零件放入清洗泵暂存区。
4. 清洗泵暂存区向货车泵装配单元线和轿车泵装配单元线供应零件。
5. 零件暂存区也直接向两条装配单元线供应零件。
6. 工位器具室向两条装配单元线提供工位器具。
7. 货车泵装好后送货车泵性能测试区，测试后送货车泵待测噪声区。
8. 轿车泵装好后送轿车泵性能测试区，测试后送轿车泵待测噪声区。
9. 两个待测噪声区的泵送噪声测试区测试噪声。
10. 噪声测试后的泵送包装区包装，再送成品库。

## 4. 书外常识补充（审核时可整节删除）
- 噪声测试需要安静的环境，外部振动和噪声会干扰测量。
- 清洗组使用清洗液，作业时有水汽和噪声。
- 性能测试要给泵通液压油，测试区有油污。
